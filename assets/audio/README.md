# Music

Three tracks, referenced by `scripts/audio/audio_controller.gd`:

| File | When it plays |
|------|---------------|
| `music_normal.ogg` | Walking the ship, nothing critical |
| `music_panic.ogg`  | A CRITICAL fault is active |
| `music_stasis.ogg` | In the pod |

These are the only sounds in the game that are not synthesised — everything short and
mechanical is generated by `scripts/audio/sound_forge.gd`.

**They are allowed to be missing.** `AudioController` checks with `ResourceLoader.exists()`,
logs once and plays silence, so the game runs and the tests pass long before the music
lands. Drop the files in and they start working with no code change.

**Loop points matter more than the composition.** Each track loops for minutes at a time, so
export them with clean loop boundaries — in Godot, tick *Loop* on the `.ogg`'s import
settings once the file is here.


# Sound effects

Everything short and mechanical is generated by `scripts/audio/sound_forge.gd` — no files, no
licences, nothing in the web build. A handful of recorded ones sit in `sfx/` and are listed in
`AudioController.FILE_SOUNDS`.

**A file OVERRIDES a generated sound of the same name.** `FILE_SOUNDS` is loaded after
`_forge()` into the same dictionary, so `sfx/Klaxon.mp3` replaces `SoundForge.klaxon()` simply
by being registered under `&"klaxon"`. The generator stays: it is the fallback when the file is
missing, and `smoke_audio.gd` still measures it directly (length, no clipping, a continuous
loop seam) rather than through the controller.

Anything the alarm plays must LOOP. `set_alarm(true)` starts it and nothing stops it until the
fault is dealt with, and an imported mp3 is one-shot by default — the controller sets
`AudioStreamMP3.loop` in code rather than relying on the `.import`, so a re-import cannot
quietly turn a klaxon into a beep.

# Voiceover

`voiceover/` holds the ship computer's lines. They are registered in
`AudioController.VOICE_LINES` under names that say what the line MEANS rather than which take
it was, so callers never see a filename:

```gdscript
Audio.say(&"oxygen_low")
Audio.say(&"intro", true)   # interrupt: clears the queue
```

- **One player, one queue.** Two computer voices over each other is not two alerts, it is
  neither — and the moment it matters is exactly when several things break at once. Lines queue
  (max `VOICE_QUEUE_MAX`, dropping the OLDEST) with `VOICE_GAP` between them.
- **Not positional.** The computer is on the PA: identical from the engine room and from inside
  a sealed pod, which is the one place the player cannot walk away from.
- **Its own bus** (`Voice`), because it speaks over the klaxon it is explaining and the two
  have to be mixable against each other.

**Wiring a line to a fault is DATA.** `Malfunction.vo_line` is an exported `StringName`, so
giving a system a voice is one field in `game.tscn` — no code change. Lines with nothing wired
to them yet are still registered, so hooking one up later stays a one-field edit.
